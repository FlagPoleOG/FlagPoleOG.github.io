About Second Shift Software

Second Shift Software is an independent publisher of native Windows apps, run by Chandler Freeman.

What it makes

  • DropTrace is a free internet outage logger. It records when your connection drops, how long it lasts and the likely cause.
  • DropTrace Pro adds packet loss and jitter tracking, a pattern finder and a report you can send to your provider.
  • FolderTrace shows which program each AppData folder belongs to and which look like leftovers.
  • HitchTrace, a game stutter finder, is in development.

How the apps are built

They are native Windows programs, not wrappers around a browser, so they stay light on memory. They need no account and have no subscription. The apps say "likely cause" because they can point to a probable reason, not prove one.
